Cette page sera remplacée par la vôtre

Vous voyez cette page d'attente parce que la publication n'est pas encore réglée sur GitHub Actions. Votre vraie page, construite depuis votre fiche, prendra sa place.

  1. Dans votre dépôt GitHub : Settings → Pages → Build and deployment → Source : GitHub Actions.
  2. Puis : Actions → Publier ma page → Run workflow.
  3. Attendez la coche verte, puis rechargez cette adresse.

Le guide complet est dans le fichier README du dépôt (étape 3). Un exemple du résultat : la page de Marie Exemple, une personne fictive.
